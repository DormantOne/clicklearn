ClickLearn: Add the HCC!

A practice run inside Example EMR, a made-up chart built for training.

Each practice patient (all fake) has 3 uncaptured chronic conditions, drawn at random from a rotating pool. Capture them and learn about each one.

  1. Click the Chronic condition recapture alert to unlock Condition review +10
  2. Click each condition name to review evidence and learn the dx +10
  3. Click Add to problem list +25, plus Add visit diagnosis for a bonus +5
  4. Hit Save review, then email aes95@pitt.edu for completion verification

Wrong clicks cost −5 and break your streak. Speed bonus at the end.

The tutorial puts a green callout on every next click. When you're ready for challenge mode, turn it off with the 🎓 button up top.
